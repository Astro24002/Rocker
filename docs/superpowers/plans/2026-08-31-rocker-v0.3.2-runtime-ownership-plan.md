# Runtime Ownership and Single Instance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every renderer-owned runtime resource a main-issued generation identity and ensure only one Electron main process can write Rocker data.

**Architecture:** Introduce a small `RuntimeOwner` value type, make `WorkspaceWindowManager` the generation authority, and migrate owner-scoped managers and IPC checks to the full owner. Keep Window-close cleanup broader than renderer-reload cleanup and isolate single-instance behavior in a testable helper.

**Tech Stack:** Electron 43, TypeScript 7, ssh2, Vitest 4.

**Spec:** [Rocker v0.3.2 Reliability Closure Design](../specs/2026-08-31-rocker-v0.3.2-reliability-closure-design.md)

## Global Constraints

- Main process creates `RuntimeOwner`; never trust a renderer-supplied generation.
- Renderer reload releases only the previous generation.
- Native Window close releases every generation for that `webContentsId`.
- Preserve multiple Rocker Windows inside one Electron main process.
- Do not change connection reuse security rules or terminal output flow.
- No cross-process file lock is introduced.

```ts
export interface RuntimeOwner {
  webContentsId: number
  rendererGeneration: number
}

export function sameRuntimeOwner(left: RuntimeOwner, right: RuntimeOwner): boolean {
  return left.webContentsId === right.webContentsId &&
    left.rendererGeneration === right.rendererGeneration
}

export function isRuntimeOwner(value: unknown): value is RuntimeOwner {
  if (!value || typeof value !== "object") return false
  const owner = value as Partial<RuntimeOwner>
  return Number.isSafeInteger(owner.webContentsId) && owner.webContentsId! > 0 &&
    Number.isSafeInteger(owner.rendererGeneration) && owner.rendererGeneration! >= 1
}

export function runtimeOwnerKey(owner: RuntimeOwner): string {
  return `${owner.webContentsId}:${owner.rendererGeneration}`
}
```

export type WindowLifecycleEvent =
  | { kind: "renderer-ready"; owner: RuntimeOwner }

- [ ] **Step 3: Implement the pre-bootstrap lock and focus behavior**

```ts
export function bootstrapPrimaryInstance(
  target: Pick<Electron.App, "requestSingleInstanceLock" | "quit" | "on" | "whenReady">,
  callbacks: { start(): Promise<void> | void; focusExisting(): void; onStartError(error: unknown): void }
): boolean {
  if (!target.requestSingleInstanceLock()) {
    target.quit()
    return false
  }
  target.on("second-instance", callbacks.focusExisting)
  void target.whenReady().then(callbacks.start).catch(callbacks.onStartError)
  return true
}
```

In `electron/main.ts`, call the helper at module startup and let it call
`startApplication` only for the primary process. The second-instance callback
may run before `runtime` exists; in that case set one pending-focus flag and
consume it after Window creation.
