# Rocker v0.7.0-rc.2 Verification

Date: 2026-09-20
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.2`

## Scope

- Local Desktop and remote SFTP home defaults; explicit persisted paths remain
  compatible. Remote `realpath(".")` is resolved by the connected SFTP server.
- Larger SFTP table text and matching pane row heights; the white window chrome
  applies only to the SFTP destination.
- Rule-backed and host-level PF pages route to the selected host's forwarding
  details. Rule status synchronization leaves the user's session label alone.
- No storage schema migration and no connection/task lifecycle changes.

## Candidate Limitations

Browser-only previews are demo data, not proof of real SSH/SFTP connectivity.
The new SFTP page has no visible transfer queue/progress and transfers do not
resume across restarts. Windows/macOS packaged installation and real-host smoke
remain manual final-release gates.
