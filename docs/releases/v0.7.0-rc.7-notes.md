# Rocker v0.7.0-rc.7

This prerelease refines the SFTP workspace around the two-pane file workflow.
The local pane opens at the Desktop, and the remote pane starts at the
connected SSH user's home directory. Files copied from Local to the host use
the real Electron SFTP bridge and appear as transfer tasks; the interactive
browser preview is explicitly backed by sample data only.

File actions are available from right-click menus, including refresh, folder
creation, rename, delete, and transfer actions. Remote deletion requires two
confirmations. Active transfers lock their source rows, while completed task
status remains visible briefly and then clears automatically.

This remains a prerelease. Real-host SFTP behavior and packaged Windows/macOS
interaction still require manual validation.
