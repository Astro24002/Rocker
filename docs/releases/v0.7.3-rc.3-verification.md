# Rocker v0.7.3-rc.3 Verification

Date: 2026-10-19
Source: `dev/v0.7-sftp`, based on `v0.7.2` (`c1cae4d`)

## Scope

- New settings default to Consolas; previously saved terminal-font preferences
  remain unchanged.
- The Host editor uses an Electron native file picker for SSH private-key paths.
  The selected path is passed through the preload bridge and existing Host save
  flow. Key file contents are not read by the picker.
- File-picker cancellation leaves the current path untouched. Picker failures
  are announced and associated with the picker control.
- No persisted schema change or migration is introduced.
- The reported generic terminal connection error on first launch is explicitly
  deferred and is not fixed or claimed verified by this RC.
