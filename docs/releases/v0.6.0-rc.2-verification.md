# Rocker v0.6.0-rc.2 Verification

Release commit: the commit tagged `v0.6.0-rc.2`.

## Scope

- Constrain each SSH terminal surface to the height and width of its assigned
  stage or split-grid cell. Terminal output no longer determines the measured
  terminal surface height used by xterm `FitAddon` and `ResizeObserver`.
- Preserve the existing controller, channel, and PTY lifecycles. A connection
  state change does not dispose xterm, and repeated observer notifications with
  identical dimensions do not send repeated SSH PTY resize requests.
- Keep the RC1 product boundary: SFTP directory operations and an embedded PF
  Browser Preview are not implemented. Do not infer HTTP from a port number.

## Verification

- Focused terminal layout, xterm lifecycle, and controller tests.
- `npm run typecheck`, `npm test -- --run`, `npm run build`, and `git diff --check`.
- Local result: 78 test files passed, 1 skipped; 726 tests passed, 1 skipped.
- GitHub Actions verify, Windows and macOS packages, six-asset allow-list, and
  prerelease job run from tag `v0.6.0-rc.2`.

Native SSH interactive inspection is still required on a configured desktop.
Local Electron cannot be launched here because its `chrome-sandbox` helper does
not have the OS-required ownership/mode. Snap Chromium also cannot start in
this environment (missing snap cgroup), so browser-pixel inspection is not
claimed. No Electron sandbox bypass is used.
