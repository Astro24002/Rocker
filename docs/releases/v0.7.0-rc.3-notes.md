# Rocker v0.7.0-rc.3

This prerelease refines the workspace navigation and forwarding workflow.
The sidebar uses larger, aligned feature and session icons and labels; the
brand mark no longer navigates. Compact session rows no longer show a close
button, while their context menu still offers Close. The SSH session's Port
forwarding command now opens the same host-specific Port Forwarding page as
the Hosts card, reusing the host's PF session without starting a forwarding
task.

Hosts can display up to seven cards across the available workspace, with
smaller layouts responding to the content width. Port Forwarding text is
larger and narrow forwarding tables remain horizontally scrollable. On
Windows, maximizing the app uses the display work area so a visible taskbar
does not cover the workspace; when the taskbar is auto-hidden and the work
area expands, the maximized window follows it. Previous normal window bounds
are preserved for restore and persistence.

This candidate retains RC2's real Electron SSH/SFTP bridge and independent
main-process connection and transfer lifecycles. The browser preview remains
demo-only. The SFTP page still has no visible transfer progress/queue or
restart-safe transfer resume. Windows work-area behavior is covered by unit
tests but still requires native verification with visible and auto-hidden
taskbars on target systems, alongside real-host and packaged-app smoke tests
before the final v0.7.0 release.
