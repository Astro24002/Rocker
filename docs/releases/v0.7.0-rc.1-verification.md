# Rocker v0.7.0-rc.1 Verification

Date: 2026-09-20
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.1`

## Scope

- Main-process SFTP manager and independent workspace/transfer leases; existing
  verified SSH transport and port-forwarding ownership remain separate.
- Unified SSH/SFTP/PF Sessions routing, per-window SFTP/PF page reuse, and
  independent new-window duplication. Old workspace records without `kind`
  continue to load as SSH; no storage migration is required.
- Fixed 50/50 Local/remote SFTP workspace: 1px divider, four rows per pane
  (42px/34px/31px/scrollable body), 36px file rows, and overlay controls.
- Local directory metadata from read-only Electron IPC; real remote listings
  and file actions from SFTP. The browser preview is demo-only.

## Candidate Gates

The tag workflow must still pass Linux verification and Windows/macOS
packaging, then publish only the six allow-listed x64/arm64 installers and
archives as a GitHub prerelease. Native Windows/macOS install, real-host
permissions/disconnect/retry, and application-exit smoke remain deferred
and must not be described as completed by CI packaging alone.

## Known RC Limitations

The new fixed two-pane SFTP page does not show a transfer queue or progress,
although tasks continue independently in the main process and close behavior
remains guarded. Transfer history and resume do not persist across restarts.
PF Browser Preview remains limited to explicitly identified HTTP/HTTPS, not
port-number guesses. No storage schema migration is introduced.
