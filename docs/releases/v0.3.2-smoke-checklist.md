# Rocker v0.3.2 Release-Candidate Smoke Checklist

> Native Windows/macOS install and launch testing is deferred beyond v0.3.2.
> This checklist is retained for a later platform validation pass and is not a
> v0 release gate.

Run this checklist against artifacts built from the exact commit that will be
tagged `v0.3.2`. The artifact filename and SHA256 are required for every row.
Do not mark a row passed when the artifact, platform, or architecture differs.

## Evidence Rules

- Use a disposable test host and record only the host alias, never a password,
  private key, username, address, or terminal transcript.
- Force the reconnect by terminating the test transport, then verify the UI
  reaches `Reconnecting` and returns with a new PTY generation.
- Confirm closing one Session does not close another Session sharing the same
  verified connection.
- Attach the sanitized diagnostics export and the exact artifact SHA256 for any
  failed or blocked row.
- Native platform execution is optional for v0.3.2 and does not gate the
  release. When this checklist is used later, all four platform/architecture
  rows should be executed on native operating systems; Linux/Wine packaging
  checks do not substitute for macOS launch or uninstall evidence.
