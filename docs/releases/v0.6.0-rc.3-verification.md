# Rocker v0.6.0-rc.3 Verification

Release commit: the commit tagged `v0.6.0-rc.3`.

## Scope

- Single-click a Host to select it without switching the Content Stage.
- Double-click a Host, press Enter, or use Open SSH to open a new SSH session
  with a distinct ID. Name successive sessions G11, G11(1), G11(2), etc.
- Preserve existing session channels and the main-process SSH/PTy lease model;
  no new IPC contract or persistent storage migration is required.
- Keep the RC2 terminal sizing fix and RC1 product boundary: no real SFTP
  directory operations or embedded PF Browser Preview.

## Verification

- HostList selection/double-click and App independent-session regression tests.
- `npm run typecheck`, `npm test -- --run`, `npm run build`,
  `git diff --check`, production dependency audit, and local short soak.
- Local result: 78 test files passed, 1 skipped; 727 tests passed, 1 skipped.
  Typecheck, build, and diff checks passed. The official npm registry reported
  zero production vulnerabilities. The 3-second soak completed 8 iterations
  and 8 reconnects with zero failures and resources back at baseline.
- GitHub Actions verify, Windows/macOS package jobs, six-asset allow-list, and
  prerelease job must pass on the `v0.6.0-rc.3` tag.

Native interactive SSH verification requires a configured Windows/macOS
desktop. This Linux environment cannot launch Electron with its existing
`chrome-sandbox` ownership/mode; a browser-only renderer cannot verify SSH.
