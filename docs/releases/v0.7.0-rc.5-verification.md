# Rocker v0.7.0-rc.5 Verification

Date: 2026-09-22
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.5`

## Scope

- Local-to-remote SFTP drag and drop using the real local path and existing
  transfer-task model, with overwrite confirmation and a non-drag upload
  fallback.
- Windows work-area maximization using outer window bounds so the taskbar is
  not covered; display work-area refresh remains supported.
- Session records are discarded on normal shutdown and stale persisted session
  records are removed during startup while window placement is retained.
- No new public Electron IPC contract or storage schema migration.

The tag workflow must still pass Linux verification and Windows/macOS
packaging, then publish only the six allow-listed x64/arm64 installers and

native Windows/macOS smoke.

## Candidate Limitations

Real Windows taskbar behavior and real-host SFTP drag/upload still require
manual packaged-app validation. Transfer progress remains represented by the
existing task model and sidebar activity state rather than a new persistent
transfer queue.
