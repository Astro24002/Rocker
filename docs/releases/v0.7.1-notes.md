# Rocker v0.7.1

This release improves SFTP transfer recovery and metadata access while keeping
the existing two-pane workspace and its four-column file table.

- A temporary transfer task list shows concurrent tasks, their routes, progress,
  and failure details without adding a permanent panel.
- Failed transfers can be retried when their source and destination remain
  available. Each active transfer can be cancelled independently.
- A Properties view exposes permissions, UID, and GID when the SFTP server
  provides them; unavailable metadata is omitted.
- SFTP integration coverage now exercises retry, same-Host concurrent
  transfers, cancellation isolation, lease cleanup, and terminal PTY isolation
  after an SFTP request failure.

Transfer tasks remain in memory and are not resumed after application restart.
No application storage migration is required.

Native packaged-app installation and real-host SFTP acceptance are tracked
separately from CI packaging and are listed as pending in the verification
record.
