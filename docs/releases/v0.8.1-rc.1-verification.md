## Release workflow and limits

The tag workflow verifies source, packages Windows x64/arm64 EXE and macOS
x64/arm64 DMG/ZIP, enforces the six-asset allow-list and publishes a prerelease.
Publication and asset metadata will be checked after the workflow completes.
Main is not pushed. v0.8.0 remains the stable release.

Native installation, real external-host acceptance and the previously reported
first-launch terminal error remain deferred. The long soak remains a v1 gate.
