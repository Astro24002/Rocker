# Rocker v0.5-D Connection Test Verification

Date: 2026-09-11
Status: Working-tree verification; not a release record
Scope: Explicit saved-Host connectivity testing

## Implemented

- Added a selected-Host `Test connection` action without changing click-to-select
  or double-click-to-connect behavior.
- Added a fresh, no-PTY SSH probe that does not acquire a terminal lease, enter
  the reusable connection map, emit connection lifecycle events, or write
  History records.
- Reused the protected Host resolver, credentials, and Host Key inspection /
  confirmation / trust / replacement flow.
- Added a bounded 30-second probe cap, cancellation handling, and guaranteed
  temporary-client cleanup.
- Added owner-scoped IPC and preload bridge coverage with safe result categories;
  raw SSH errors, credentials, key paths, and fingerprints stay in the main
  process.
- Added a deterministic browser-preview result for UI review.

## Security and Compatibility Notes

- A probe always creates an independent transport, even when an equivalent
  terminal connection is already ready. Existing leases and retry state are
  unchanged.
- Host Key approval follows the normal trust policy. Rejection returns only the
  `host-key-rejected` category; no fingerprint or prompt detail is serialized
  to the renderer.
- Resolver failures are reduced to the existing bounded failure categories.
- The browser preview mirrors the bridge shape without attempting native SSH.
