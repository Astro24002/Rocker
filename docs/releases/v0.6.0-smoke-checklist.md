# Rocker v0.6.0 Port Forwarding Smoke Checklist

This is a manual product smoke checklist for the v0.6 forwarding manager. Run
the native portion against a disposable SSH Host. Record only a Host alias,
date, result, and sanitized diagnostic export path when needed. Never record a
password, private key, username, address, Host Key, or terminal transcript.
