Rocker v0.6.0-rc.3 is a prerelease of the unified desktop SSH workspace.

Hosts now select on single click without leaving the Hosts workspace. Double
clicking a Host opens a new SSH terminal session even when that Host already has
an active session. Sessions are numbered independently (G11, G11(1), G11(2));
the existing session is not replaced or reconnected. Enter and the Host's
Open SSH menu action also open new sessions. Connection History and SSH command
search retain their existing activation behavior.

This candidate also contains the RC2 terminal sizing fix. SSH sessions use the
Electron main-process connection manager and xterm. Port forwarding remains
owned independently of page visibility.

Known limits: SFTP provides a workspace route with persisted browser-state
metadata, not real directory listing or transfers. Embedded PF Browser Preview
is not available. Native Windows/macOS SSH interaction and packaging smoke
still require verification on a configured desktop.
