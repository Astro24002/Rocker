## Evidence Rules

- Use a disposable test host and record only the host alias, never a password,
  private key, username, address, or terminal transcript.
- Force reconnect by terminating the test transport, then verify the UI reaches
  `Reconnecting` and returns with a new PTY generation.
- Confirm closing one Session does not close another Session sharing the same
  verified connection.
- Attach the sanitized diagnostics export and exact artifact SHA256 for any
  failed or blocked row.
- Linux/Wine packaging checks do not substitute for native macOS launch or
  uninstall evidence; those rows remain deferred until a later native pass.
