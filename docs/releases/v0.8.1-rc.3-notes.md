# Rocker v0.8.1-rc.3

- Port forwarding cards in the overview and Host workspace adapt between
  360px and 480px, with the remote port, status and actions on one line.
- Name, Local and Remote appear below the divider. Forwarding, Stopped and
  Error use consistent green, gray and red status badges.
- Host rule details show the current forwarding error and errors captured in
  the current view under Log. Edit, open session and address actions remain
  available in details. Share copies the SSH forwarding command and removal
  asks for confirmation.

The existing forwarding service and connection lifecycles are unchanged; no
storage migration is required. Log is not a persistent history. The overview
details action opens the Host workspace, where rule details and Log are
available. Design-comparison pages are not included.

Native installation and real external-host acceptance remain deferred, as does
the previously reported first-launch terminal issue. This is a prerelease.
