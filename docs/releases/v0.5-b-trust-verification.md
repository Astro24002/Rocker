# v0.5-B Trust Verification

Date: 2026-09-11
Status: Implemented in the working tree; not a release record
Scope: Host Key Trust inventory, audit history, and expected-fingerprint removal

## Implemented

- Added the dedicated Trust Workspace route and Sidebar/Command Palette entry.
- Added typed preload and IPC list/remove operations with renderer-owner
  checks, bounded request validation, and serialized removal mutations.
- Extended `host-keys.json` with a normalized, legacy-compatible audit history
  capped at 500 records. Trust, replacement, and removal are recorded without
  raw key material or credentials.
- Added a compact Trust view with endpoint/fingerprint search, newest-first
  activity, explicit removal confirmation, generic unavailable/error states,
  and English/Simplified Chinese labels.
- Kept re-trust on the existing native Host Key confirmation path; no silent
  trust replacement was added.
