# Rocker v0.6.0-rc.5 Verification

Release commit: the commit tagged `v0.6.0-rc.5`.

## Scope

- Add a trailing Session close control that appears on row hover or keyboard
  focus and dispatches the existing `session.close` command guard.
- Keep close clicks independent of Session activation and workspace navigation.
- Disable the inline close control while a Session is closing.
- Replace the Session kind icon with the close control on compact Sidebar hover
  so the two controls do not overlap.
- Remove the bottom Target, Type, and Status strip and let the active SSH, SFTP,
  or PF content occupy the complete Content Stage.
- Preserve Electron main-process SSH/PTy and forwarding lease ownership. No IPC
  contract or persistent storage migration is required.

## Verification

- Sidebar tests cover close command dispatch, click isolation, disabled closing
  state, accessible naming, and stable hover layout.
- App tests assert that the removed information strip is absent for SSH, SFTP,
  and PF workspace routes while Session switching and per-type state remain.
- `npm run typecheck`, `npm test -- --run`, `npm run build`,
  `git diff --check`, production dependency audit, and local short soak passed.
- Local result: 78 test files passed, 1 skipped; 740 tests passed, 1 skipped.
  The official npm registry reported zero production vulnerabilities. The
  3-second soak completed 9 iterations and 9 reconnects with zero failures and
  resources back at baseline.
- Browser renderer checks at 1280x800 confirmed that the trailing close control
  does not overlap the Session name, the 58px compact Sidebar swaps the kind icon
  for Close, and no `.session-info-bar` remains. The terminal surface and Content
  Stage both measured 1060x648 after the strip was removed. Browser preview uses
  the mock bridge and is not evidence of a real SSH connection.
- GitHub Actions verify, Windows/macOS package jobs, six-asset allow-list, and
  prerelease job must pass on the `v0.6.0-rc.5` tag.

Native interactive SSH verification requires a configured Windows/macOS
desktop. This Linux environment does not substitute browser mock behavior for a
real SSH, SFTP, or packaged-app smoke test.
