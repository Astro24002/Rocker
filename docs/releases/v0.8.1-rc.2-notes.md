# Rocker v0.8.1-rc.2

- PF overview and Host details now use the approved divided card layout:
  status dot before the rule name, status and actions together at the upper
  right, and Local/Remote addresses below a divider.
- Cards adapt to available width, with a 480px minimum and 640px maximum
  (shrinking to fit containers below the minimum). Long names truncate and
  addresses wrap.
- Rules sort numerically by local port, then remote port. Overview groups still
  show two rules initially; these are now the first two by port order rather
  than the two most recently created. Each Host expands independently.
- Active Forwarding has a green background, border and bold label, with a
  semantic green state indicator across themes.

Existing actions, SSH connections and forwarding lifecycles are preserved.
No storage migration is required. Design-comparison pages are not included.

Validation: 872 tests passed with one intentional soak skip; TypeScript and
production build passed. Production UI browser checks covered twelve fixture
rules, three themes, four window widths, sorting, expansion and start/stop.
These checks do not represent real external-host acceptance.

Native installation, real external-host acceptance and the previously reported
first-launch terminal error remain deferred. This is a prerelease; v0.8.0
remains the stable release.
