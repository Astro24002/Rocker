# Rocker v0.4.0 Release Smoke Checklist

This checklist supports the v0.4.0 Terminal Productivity release. It is a
manual product smoke checklist, not native Windows/macOS startup or installer
sign-off; those checks remain deferred for the v0 line.

Run manual checks against a disposable SSH host. Record only the host alias,
date, result, and sanitized diagnostic export path when needed. Never record a
password, private key, username, address, Host Key, or terminal transcript.

Result values: `PASS`, `FAIL`, `BLOCKED`, `DEFERRED`, or `PENDING`.

## Search

Result: `PENDING`
Date (UTC):
Notes:

- [ ] Open an active SSH Session and generate at least 10,000 lines of
  scrollback without moving terminal output into a visible React output panel.
- [ ] Open Search with `Ctrl+Shift+F` on Windows or `Cmd+Shift+F` on macOS.
- [ ] Search as the user types, move to the next result with `Enter`, and move
  to the previous result with `Shift+Enter`.
- [ ] Exercise case-sensitive, whole-word, and regular-expression options.
- [ ] Confirm the match count and current result are shown when available, and
  an explicit no-results state appears for a missing query.
- [ ] Close with `Escape`; confirm focus returns to the terminal and terminal
  input, PTY state, SSH state, and scrollback remain unchanged.
- [ ] Switch Sessions and confirm each Session retains only its own search
  query and result state.

## Command Palette

Result: `PENDING`
Date (UTC):
Notes:

- [ ] Open the centered palette with `Ctrl+Shift+P` on Windows or `Cmd+Shift+P`
  on macOS.
- [ ] Confirm empty-query Recent Sessions appear in recency order and a query

## Shell Key Pass-Through

Result: `PENDING`
Date (UTC):
Notes:

- [ ] With terminal input focused, verify these common shell combinations reach
  xterm/the remote shell and are not intercepted by the global command layer:
  `Ctrl+C`, `Ctrl+D`, `Ctrl+Z`, `Ctrl+L`, `Ctrl+A`, `Ctrl+E`, `Ctrl+F`,
  `Ctrl+K`, `Ctrl+U`, and `Ctrl+W`.
- [ ] Confirm only `Ctrl/Cmd+Shift+F` and `Ctrl/Cmd+Shift+P` open global
  surfaces; unrecognized key events remain terminal input.
- [ ] Confirm a terminal `Ctrl+C` with no selection sends an interrupt rather
  than opening or executing an application command.
