# Rocker v0.7.0-rc.1

This prerelease introduces the SFTP workspace alongside the existing SSH
terminal and port-forwarding sessions. The file workspace is a light, equal-width
Local/remote two-pane table. The desktop app browses local directories through
read-only Electron IPC and remote directories through the real SSH/SFTP bridge.
Users can open directories, navigate paths, filter rows, and use file actions
including upload, download, rename, and removal. No bottom transfer panel or
additional SFTP sidebar destination is added.

SSH, SFTP, and PF sessions retain independent window-local pages. Transfer
tasks have their own main-process leases, so hiding or closing the page does
not silently turn an in-progress transfer into a browser simulation. The
browser-only preview remains demo data and is not evidence of SSH/SFTP access.

This RC does not include a visible transfer progress/queue interface in the
new two-pane page or restart-safe transfer resume. Windows/macOS native
real-host smoke and packaged-app behavior require validation on the target
platforms before the final v0.7.0 release.
