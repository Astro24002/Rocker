# Rocker v0.8.0

## Changes

- Open Forwarding from a Host now establishes its own background SSH connection.
  Remote-service discovery works without an open terminal. Existing verified
  connections are reused, switching pages preserves discovery results, and
  closing a PF page leaves running forwarding rules independent.
- SSH History records connected time and final outcomes. Automatic reconnect
  waits are excluded; separate sessions are timed independently. Clearing
  History no longer allows active sessions or stale reads to restore old rows.
  Interrupted sessions show a recorded lower bound instead of invented duration.
- SFTP cancellation handles channel closure and missing or late callbacks, waits
  for cleanup, and preserves other transfers and terminal sessions sharing SSH.
- Forwarding uses explicit Save, Save and start, Start and Resume actions. The
  ineffective startup-policy control has been removed.
- Snippets navigation, Host settings and command entries have been removed.
- Includes the v0.7.3 RC3 improvements: Consolas for new terminal preferences and
  a native file picker for SSH private-key paths.

## Compatibility

Existing terminal preferences are preserved. History adds optional metadata;
legacy zero-duration rows display Unknown. Forwarding documents keep their
version and legacy autoStart value, which does not authorize starting listeners.
No manual data migration is required.

## Validation and remaining work

The release source passes 871 tests (one intentional soak skip), TypeScript,
production build, a short SSH soak and the production dependency audit.
The release workflow builds Windows x64/arm64 EXE and macOS x64/arm64 DMG/ZIP.

Named workspace save/restore remains planned and is not included. Native
installed-app and real external-host acceptance remain deferred, as does the
reported generic terminal connection error on first launch. The long soak
remains a v1 gate. This release does not claim those checks are complete.
