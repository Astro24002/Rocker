# Rocker v0.7.1 Verification

Date: 2026-10-10
Source: `dev/v0.7-sftp`, release commit tagged `v0.7.1`

## Scope

- Transfer tasks can be inspected in a temporary task list with route, progress,
  failure details, retry, independent cancellation, and dismissal.
- File Properties expose permissions, UID, and GID only when returned by the
  SFTP server. The file table retains its existing four columns.
- Integration coverage exercises failed-download retry, concurrent transfers
  for one Host, cancellation isolation, transfer lease cleanup, and continued
  terminal PTY use after an SFTP request fails on the shared transport.
- Transfer tasks remain runtime-only. No storage schema or restart-resume
  migration is introduced.

## Publication Workflow

Pushing `v0.7.1` runs `.github/workflows/build.yml`: Linux tests, typecheck,
build and dependency audit, followed by Windows and macOS packaging. The v1
long soak is skipped for v0 tags by design. If the required jobs pass, the
release job publishes only the six allow-listed x64/arm64 Windows installers
and macOS DMG/ZIP assets. At the time this record was prepared, the tag workflow
had not yet run.
