# Rocker v0.7.0-rc.4 Verification

Date: 2026-09-21
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.4`

## Scope

- Hosts cards and sidebar mark alignment; favorite/edit buttons have hover,
  keyboard-focus, and touch access.
- Port Forwarding overview grouped by Host, newest two rules per Host visible
  by default; separate details, start/pause, confirmed delete, and SSH command
  copy actions. The command uses saved connection/forwarding addresses and SSH
  port, validates its shell arguments, and supports IPv6 endpoints.
- Deleting a saved rule removes this window's PF session profile reference
  without closing another session. Stopping a forward retains its saved rule
  for later restart.
- Per-client remote channel refusal closes the client socket without removing
  the local listener or SSH lease. A subsequent local connection can recover.
- No storage schema migration or new public Electron IPC contract.

## Candidate Limitations

Browser-only previews use demo data and do not prove real SSH/SFTP behavior.
Windows/macOS packaged installation, real-host forwarding, and SFTP file and
transfer operations remain manual final-release gates. The SFTP page still
lacks a visible transfer queue/progress and restart-safe transfer resume.
