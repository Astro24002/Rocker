# Rocker v0.7.0-rc.2

This prerelease updates the two-pane SFTP workspace. Local starts in the
operating system's Desktop directory; a new remote workspace resolves the
connected user's home directory through the real SFTP server. Explicitly saved
remote paths remain unchanged. The SFTP page now has larger text and a white
window chrome, with table row and header heights adjusted to fit.

Port Forwarding sessions now open their host details at Rocker / Port
Forwarding / <host>, whether entered from a forwarding rule, the Sessions list,
or a restored rule-backed session. Forwarding rule names no longer overwrite
the PF session label, including labels explicitly renamed by the user. Existing
saved labels are not rewritten automatically.

This candidate retains RC1's real Electron SSH/SFTP bridge and independent
main-process transfer leases. The browser preview is demo-only. The SFTP page
still has no visible transfer progress/queue or restart-safe transfer resume.
Native Windows/macOS installation, real-host operations, and packaged-app
behavior remain to be checked on target systems before the final v0.7.0 release.
