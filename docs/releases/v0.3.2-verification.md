## Unresolved Release Evidence

- Native Windows and macOS install/launch/reconnect/uninstall smoke is deferred
  beyond v0.3.2. The existing checklist remains available for a later native
  platform validation pass.
- The local Windows staging directory also contains electron-builder's
  unpacked payload, blockmaps, and an intermediate archless installer. The CI
  upload pattern and release allow-list copy only the six versioned x64/arm64
  installer/archive assets, so these files are not published as release assets.
- The Windows container uses the pinned official
  `electronuserland/builder:24-wine` image. It retains platform optional
  binaries needed by Vite/electron-builder, then removes only ssh2's optional
  `cpu-features`/`nan` accelerators before packaging so Wine never tries to
  cross-compile them.
- The approved storage/bootstrap recovery plan is not yet implemented in this
  branch. Until that plan is completed and verified, v0.3.2 is not release-ready
  even though the reliability and soak checks above pass.

## CI Gate

- The `soak` job runs only for a `v*` tag or explicit `workflow_dispatch` and
  has a 45-minute timeout.
- The release job requires both `package` and `soak`.
- Release publication is limited to the six allow-listed versioned installer
  and archive assets.
