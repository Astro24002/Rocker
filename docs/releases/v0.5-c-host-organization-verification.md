Date: 2026-09-11
Status: Working-tree verification; not a release record
Scope: Optional Host environment and tag metadata

## Implemented

- Added optional `production`, `staging`, `development`, and `personal`
  environment values to `HostProfile`.
- Added bounded, trimmed, case-insensitively deduplicated tags (up to 16 tags,
  64 characters per tag).
- Added Environment and Tags controls to the shared New/Edit Host drawer.
- Added exact Environment and Tag selectors and metadata-aware search to Hosts.
- Added an explicit production-host deletion warning.
- Preserved environment and tags in safe Host duplication without copying
  credentials, key paths, snippets, or favorites.
- Mirrored normalization and duplication in the browser preview bridge.

## Security and Compatibility Notes

- Environment and tags are non-secret profile metadata. Credentials remain in
  the existing protected credential store and are not added to Host documents.
- Unknown legacy environment values and malformed stored tags are omitted on
  normalization; valid legacy Host profiles remain readable.
- IPC rejects unknown environments and out-of-bounds tag entries before the
  Host mutation queue runs.
- Production deletion uses a stronger confirmation message; canceling leaves
  the Host unchanged.
