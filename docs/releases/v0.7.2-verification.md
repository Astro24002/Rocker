# Rocker v0.7.2 Verification

Date: 2026-10-10
Source: `dev/v0.7-sftp`, tag `v0.7.2`

## Scope

- Recursive local-to-remote and remote-to-local directory copies run through
  the existing SFTP transfer manager as individual tasks.
- Both panes support copy drag-and-drop. Transferring source entries are
  disabled until completion or failure, and the destination listing refreshes
  after completion.
- The Show hidden files option remains selected across a same-session listing
  refresh after deletion and resets for a newly selected SFTP session.
- No storage schema or transfer-recovery migration is introduced.

## Publication Workflow

Pushing `v0.7.2` runs `.github/workflows/build.yml`: tests, typecheck, build,
and production dependency audit, followed by Windows and macOS packaging. If
the required jobs pass, the release job publishes the six allow-listed x64 and
arm64 Windows installer and macOS DMG/ZIP assets. The v1 long soak is skipped
for v0 tags by design.
