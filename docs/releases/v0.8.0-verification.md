## Scope and source

- PF workspace-owned SSH discovery connection, independent of terminal PTYs
  and running forwarding rules.
- History lifecycle, checkpoints, clear suppression and backward compatibility.
- SFTP cancellation settlement and cleanup, controlled asynchronous regression
  tests, and Snippets removal.
- Release version is selected by the product owner. Named workspace save/restore
  has not been implemented and remains separate planned work.
- Local SFTP prototype files and unrelated untracked historical documents are
  not included in the release commit. Main is not updated.
