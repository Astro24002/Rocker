The tag triggers `.github/workflows/build.yml`: verify, Windows/macOS packaging,
then release. `scripts/verify-release-assets.mjs` requires exactly six versioned
assets: x64/arm64 EXE, DMG and ZIP. The final GitHub Release and workflow result
are checked after completion; pushing the tag alone is not publication success.
