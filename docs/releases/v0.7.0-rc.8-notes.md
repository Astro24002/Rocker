# Rocker v0.7.0-rc.8

The SFTP workspace now follows the application's active theme and uses a
`ROCKER / SFTP / Host` route breadcrumb instead of a separate workspace title.

Host names are now unique on this device, ignoring surrounding whitespace,
Unicode compatibility differences, and letter case. The editor reports name
conflicts, while local storage, duplicate actions, OpenSSH imports, and
configuration imports enforce or generate unique names. Existing duplicate
names receive stable numeric suffixes when loaded without changing Host IDs or
the storage schema.

This remains a prerelease. Packaged Windows/macOS installation and real-host
SFTP validation still require manual testing.
