# Rocker v0.7.0-rc.8 Verification

Date: 2026-09-24
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.8`

## Scope

- The SFTP route displays `ROCKER / SFTP / Host` and follows the active
  application theme through semantic design tokens.
- Host names are unique per device after trimming, Unicode NFKC normalization,
  and case-insensitive comparison.
- Host name conflicts are checked in the editor and rechecked at the storage
  mutation boundary. Duplicate, OpenSSH import, and configuration import paths
  assign unique names.
- Legacy duplicate names receive deterministic suffixes at read normalization;
  Host IDs and the persisted schema are unchanged. Normalized names are written
  back with the next store mutation; there is no standalone migration.
