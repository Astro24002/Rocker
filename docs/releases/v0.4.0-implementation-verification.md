## Scope Verified

- Per-Session terminal search remains renderer-local and uses the xterm SearchAddon.
- Command Palette, terminal context actions, session menus, and visible actions use the shared command surface.
- Shell key combinations remain available to xterm and the remote shell.
- Session rename, duplicate, split, close, and recent ordering preserve the existing owner and connection contracts.
- Live terminal appearance changes apply without reconnecting or clearing a Session.
- Blocked Settings persistence leaves temporary appearance changes active without claiming they were saved.
- SFTP, Snippets, and Local Terminal remain reachable placeholders.
- Production dependencies remain limited to `ssh2`; `@xterm/addon-search` remains development-only.

## Environment Limits

- Verification host: Linux development environment. The repository requires
  native Windows or macOS for native packaged application startup coverage.
- `npm run build` verifies Electron bundles only; installers are produced by the
  tagged GitHub Actions package jobs.
- The native Windows/macOS startup checks are `DEFERRED` for the v0
  implementation line, along with native install, reconnect, close, uninstall,
  and packaged-artifact checks.
- The 30-minute long soak is a v1 release gate and is `DEFERRED` for v0.4.
  The bounded local soak above is only a smoke signal.
- Windows/Wine packaging and native macOS packaging were not used to claim
  release artifacts in this implementation record.

## Release Boundary

The workflow continues to build only Windows and macOS installer/archive
targets. Its long-soak job remains gated to `v1.*` tags or an explicit manual
workflow dispatch, with a 45-minute job timeout. Tag `v0.4.0` publishes the
release assets after the verification and platform package jobs succeed; it
does not imply native startup coverage was performed on this Linux host.

The manual workflow is [the v0.4 smoke checklist](./v0.4.0-smoke-checklist.md).
