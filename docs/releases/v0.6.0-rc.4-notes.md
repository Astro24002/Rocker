Rocker v0.6.0-rc.4 is a prerelease of the unified desktop SSH workspace.

The Sidebar now uses a more spacious, consistently aligned navigation and
Session layout. Selected destinations connect directly to the Content Stage
with continuous outer and concave corners, without the previous accent stripe
or mismatched persistent outline. Keyboard focus remains visible without
drawing a box around the entire selected surface.

The Session context menu is now a fixed overlay, so opening it does not expand
or horizontally scroll the Sessions list. Its actions are ordered as Duplicate,
Duplicate in a new window, Rename, Port Forwarding, and Close. Duplicate opens
an independent SSH Session in the current window and assigns the next available
display name, for example G11, G11 (1), and G11 (2).

This candidate preserves the existing Electron main-process SSH/PTy and port
forwarding lease ownership. It does not add a renderer-owned connection path or
change persistent storage formats.

Known limits: SFTP provides a workspace route with persisted browser-state
metadata, not real directory listing or transfers. Embedded PF Browser Preview
is not available. Native Windows/macOS SSH interaction and packaging smoke
still require verification on configured desktops.
