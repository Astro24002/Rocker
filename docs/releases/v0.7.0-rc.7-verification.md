# Rocker v0.7.0-rc.7 Verification

Date: 2026-09-24
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.7`

## Scope

- The SFTP workspace uses the production `SftpWorkspacePage` in the standalone
  browser preview. The preview bridge is in-memory sample data and does not
  represent a real SSH or SFTP connection.
- The local pane starts at Desktop; the remote pane resolves the connected
  SSH user's home directory.
- Local-to-remote file copies, remote moves, and transfer status use the
  Electron SFTP bridge and task lifecycle.
- Context-menu operations include refresh, new folder, rename, delete, and
  transfer actions. Remote deletion requires two confirmations.
- Active transfer source rows cannot be selected or dragged. Completed task
  status is automatically dismissed after one minute.
- No persistence schema migration is introduced.

publish only the six allow-listed x64/arm64 installer and archive assets. The
v1 long soak is skipped by design. Automated preview tests do not replace
packaged-app validation against a real SSH host.

## Candidate Limitations

Real-host SFTP actions and native Windows/macOS packaged interaction still
require manual validation. Remote rename has no byte-level progress callback,
so its progress indicator is indeterminate. Transfers do not resume across
application restarts.
