## Release procedure

The existing `desktop-build` workflow runs tests, TypeScript, production
builds and the production dependency audit before Windows/macOS packaging.
The tag is a prerelease and must not replace stable latest. The v0 policy
uses a local short SSH soak; the 30-minute CI soak is reserved for v1 tags or
manual workflow dispatch.

The release asset allow-list requires exactly six versioned files: x64 and
arm64 NSIS EXE, DMG and ZIP. Local design-comparison pages, unrelated draft
documents and AGENTS.md are excluded from this release commit.
