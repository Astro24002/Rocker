# Rocker v0.7.0-rc.9

The SFTP workspace now hides dotfiles by default, with independent controls for
the Local and remote panes. Hidden-file visibility is session-local and is not
remembered after closing the SFTP workspace. All four file columns are
sortable; Name defaults to ascending order.

The Forest SFTP workspace uses a light neutral-gray surface. Its route
breadcrumb and native window chrome use the same scoped surface only while SFTP
is active; other workspaces retain their existing theme colors.

This remains a prerelease. Browser previews use demonstration data and do not
prove SSH/SFTP connectivity. Real-host SFTP checks and native Windows/macOS
installation and launch checks remain before the final v0.7.0 release.
