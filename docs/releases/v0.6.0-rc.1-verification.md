Date: 2026-09-17

Release type: GitHub prerelease

## Release Boundary

This candidate publishes the unified workspace shell and the existing real
Electron runtime contracts:

- untitled Sessions list and one active Content Stage;
- Hosts, SFTP, Snippets, Port Forwarding, Connections, and Settings navigation;
- English default with optional Simplified Chinese;
- host search, favorites, sorting, compact cards, and Connections History/Trust;
- SSH sessions backed by the main-process SSH connection manager, PTY lease,
  RockerBridge, and xterm;
- independent copied SSH sessions;
- PF sessions mapped to the main-process forwarding manager, with forwarding
  lifecycle independent from page visibility;
- scoped global/per-host themes and backward-compatible settings/workspace
  normalization.

SFTP is intentionally described as an on-demand workspace route with persisted
path metadata only. There is no SFTP main-process service or bridge API in this
repository, so the candidate does not claim real directory listing, transfers,
or browser-simulated SFTP. Browser Preview is deferred and no protocol is
inferred from a port number.

## CI Packaging Gate

The tag triggers `.github/workflows/build.yml`:

1. Ubuntu runs install, tests, typecheck, renderer/main build, and production
   dependency audit.
2. Windows builds x64 and arm64 NSIS installers.
3. macOS builds x64 and arm64 DMG and ZIP assets.
4. The release job validates exactly these six assets, uploads them, and marks
   `v0.6.0-rc.1` as a GitHub prerelease.

Native Windows/macOS startup and real SSH/SFTP manual checks remain product
owner follow-up for this candidate. No long v1 soak is required for a v0 tag.
