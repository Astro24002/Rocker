# Rocker v0.5.x Verification Record

Date: 2026-09-11
Scope: Windows and macOS desktop application
Status: `v0.5.5` implemented and locally verified; release tag remains product-owner controlled

## Scope Amendment

The v0.5.0 capability boundary is Hosts, Trust, Host organization, and explicit
Connection Test. Session Security Summary, Host Charset / Terminal Theme Runtime,
and 1,000-host product-scale acceptance were removed from the v0.5 exit gate.

The first two are deferred cross-layer capability tracks for a later large
version design review. The 1,000-host check remains optional engineering
benchmark evidence after the list interaction contract is stable; it is not a
v0.5 product feature or release blocker. Reserved Host `charset` and
`themeColor` metadata remains storage-compatible but is not claimed to affect
active terminal Sessions.

## v0.5.1 Accessibility and Keyboard Semantics

Implemented:

- Active navigation exposes `aria-current="page"`.
- Host cards select with Space and connect with Enter while preserving the
  pointer rule of single-click select and double-click connect.
- Host group and Recent filters expose `aria-pressed` state.
- English/简体中文 language buttons expose `aria-pressed` state.
- Session context menus open from the Context Menu key and Shift+F10, reuse the
  existing pointer menu, and preserve Escape/outside-dismiss focus restoration.
- Buttons, inputs, selects, textareas, Session menu items, and custom actions
  use the shared `--focus` 2px visible ring. The Sidebar resize separator keeps
  its keyboard width controls and has an explicit focus ring.
- No global shortcut family or SSH transport behavior was added or changed.

## v0.5.3 Platform-Aware Window Chrome

Implemented:

- The frameless shell reads the typed `bridge.app.platform` value. Windows
  keeps minimize, maximize/restore, and close controls on the right; macOS puts
  the same controls in a left traffic-light-compatible zone.
- The remaining 32px chrome remains a visually blank, draggable region and the
  right Workspace still has no Session, Host, Search, Command Palette, or
  terminal title strip.
- Maximize/restore presentation uses a typed `isMaximized()` bridge query and
  renders localized accessible names and distinct Square/Copy icon states.
- The main-process `rocker:window:is-maximized` handler is owner-window scoped;
  it returns `false` when no BrowserWindow is available and does not alter
  existing minimize, toggle, or close actions.

Focused command:

```text

```

Result: 2 files passed, 65 tests passed. The IPC registration test also covers
the maximize-state handler as part of the focused bridge verification.

## v0.5.4 Workspace Interaction Resilience

Implemented:

- Hosts remains mounted in a hidden destination surface while another route is
  active, preserving selected Host and local filter state when the user returns.
- Session menu state closes when navigation changes and restores focus to its
  origin button through the existing focus-return path.
- Terminal Sessions and controllers remain mounted across destination changes;
  Sidebar width and compact-state changes do not recreate the active terminal.
- Workspace stage, destinations, view headers, and action groups now carry
  zero-width-safe flex constraints for the supported minimum desktop window.
- Reserved Host `charset` and `themeColor` metadata remain storage-compatible
  but are intentionally outside this runtime patch.

## v0.5.5 Visual Polish and Desktop Resilience

Implemented:

- Overlay, scrim, status-surface, and platform-mark colors use semantic tokens;
  touched layout/component styles contain no local rgba/hex literals.
- Host title tracking is non-negative and compact state/action copy remains at
  readable sizes.
- View headers and action groups wrap at constrained widths, with min-width and
  overflow-safe children so selected Host actions remain reachable.
- `prefers-reduced-motion: reduce` shortens transitions and disables the generic
  refresh spinner and data-protection pending spinner.
- Existing Host card content and the invisible-at-rest resize indicator remain
  unchanged.
