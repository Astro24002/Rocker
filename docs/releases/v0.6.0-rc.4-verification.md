# Rocker v0.6.0-rc.4 Verification

Release commit: the commit tagged `v0.6.0-rc.4`.

## Scope

- Align and enlarge navigation and Session icons and labels while preserving
  compact Sidebar behavior and long-name truncation.
- Join selected navigation and Session rows to the Content Stage with continuous
  concave corners and no persistent outline or leading accent stripe.
- Render the Session context menu above its scrolling list, preserving the
  source row, keyboard opening, Escape dismissal, and focus restoration.
- Expose Duplicate, Duplicate in a new window, Rename, Port Forwarding, and
  Close in that order. Number current-window SSH duplicates as G11 (1), G11 (2),
  and so on without reconnecting or replacing existing Sessions.
- Preserve the Electron main-process SSH/PTy and forwarding lease model. No IPC
  contract or persistent storage migration is required.

## Verification

- Sidebar selection, menu overlay, action ordering, focus, mixed Session kind,
  and duplicate naming regression tests.
- `npm run typecheck`, `npm test -- --run`, `npm run build`,
  `git diff --check`, production dependency audit, and local short soak.
- Local result: 78 test files passed, 1 skipped; 737 tests passed, 1 skipped.
  Typecheck, build, and diff checks passed. The official npm registry reported
  zero production vulnerabilities. The 3-second soak completed 9 iterations
  and 9 reconnects with zero failures and resources back at baseline.
- Browser renderer checks at 1280x800 and 1040x680 confirmed continuous selected
  corners, aligned navigation/Session rows, a non-scrolling context-menu overlay,
  the five-action menu order, and G11 -> G11 (1) duplication. Browser preview
  uses the mock bridge and is not evidence of a real SSH connection.
- GitHub Actions verify, Windows/macOS package jobs, six-asset allow-list, and
  prerelease job must pass on the `v0.6.0-rc.4` tag.

Native interactive SSH verification requires a configured Windows/macOS
desktop. This Linux environment cannot launch Electron with its existing
`chrome-sandbox` ownership/mode; a browser-only renderer cannot verify SSH.
