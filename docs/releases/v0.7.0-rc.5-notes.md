# Rocker v0.7.0-rc.5

This prerelease makes the SFTP workspace support the primary dual-pane
interaction: local files can be dragged from the Local pane into the remote
pane. The drop uses the real local path and enters the existing SFTP selection,
overwrite confirmation, and transfer-task pipeline. System file-manager drops
and the Upload selected action remain available as alternatives.

The Windows custom maximize path now applies the display work area to the
window outer bounds. This prevents a borderless window from extending over the
Windows taskbar and continues to follow taskbar auto-hide work-area changes.

Workspace session snapshots are discarded when Rocker exits and stale session
records from older builds are cleared at startup. Window placement metadata is
retained, while SSH, SFTP, and PF sessions remain temporary. Settings copy now
describes this behavior accurately.

This remains a prerelease. Native Windows/macOS installation, real-host SFTP
file operations, transfer progress, and task recovery still require manual
validation before final v0.7.0 release.
