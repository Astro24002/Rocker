# Rocker v0.7.3-rc.3

This prerelease improves SSH host setup and terminal defaults.

- New installations default to Consolas for terminal text. Existing saved font
  preferences are preserved.
- The Host editor can open the native file picker to select an SSH private key.
  Rocker stores the selected path with the Host profile; the picker does not
  read or expose key contents.
- The change is backward-compatible and does not require a storage migration.

The reported generic terminal connection error on first launch is not addressed
in this candidate. Native installed-app testing and real-host SSH validation are
deferred from this RC acceptance.
