# Rocker v0.7.0-rc.6

This prerelease adds remote-to-remote SFTP file and folder moves. Dragging a
remote item onto a remote folder starts a real SFTP rename task in the Electron
main process. The source item is locked against selection and dragging while
the move is queued or running.

The SFTP workspace shows a single-line move status and indeterminate progress
inside its white workspace area only while a move is active. It disappears when
the move completes, fails, or is cancelled. Upload and download tasks do not
show this move-only status row.

Windows work-area maximization temporarily disables window resizing so the
frameless window remains within the display work area and does not cover the
taskbar. The original resizable setting is restored when the window returns to
its previous size.

This remains a prerelease. Packaged Windows/macOS installation, real-host SFTP
file and folder moves, and taskbar behavior still require manual validation.
Move progress is indeterminate because the remote rename operation does not
report byte progress. Transfers and tasks are not resumed after application
restart.
