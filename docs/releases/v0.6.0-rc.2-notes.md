Rocker v0.6.0-rc.2 is a prerelease of the unified desktop SSH workspace.

Fix: the SSH terminal surface now fills a bounded workspace cell. Terminal
output can no longer determine the container height measured by xterm's fit
observer, preventing the terminal area from repeatedly shifting after a
connection opens. SSH/PTy session ownership and forwarding leases are unchanged.

This candidate includes the RC1 workspace: unified untitled Sessions, compact
Hosts with favorites and sorting, Connections History/Trust, and scoped themes.
SSH sessions use the Electron main-process connection manager and xterm. Port
forwarding remains owned independently of page visibility.

Known limits: the SFTP destination is a workspace route with saved path state,
not a real file browser or transfer service. Embedded PF Browser Preview is
not available. Native SSH interaction and terminal stability still need a
manual check on a configured Windows/macOS desktop; automated tests and
packaging alone do not provide that evidence.
