# Rocker v0.8.1-rc.1

This release candidate presents Port Forwarding rules as cards in both the
global overview and Host detail workspace.

- Overview cards remain grouped by Host, with the newest two rules visible
  initially and the remaining rules available through expansion.
- Rule cards bring the name, local and remote addresses, status and existing
  actions together. Discovered services also use cards with adjacent controls.
- Responsive grids handle narrow windows and long names and addresses.
- PF surfaces and controls follow dark and light themes correctly.

No storage migration is required. Existing SSH connections and forwarding
lifecycles are unchanged.

Native installed-app and real external-host acceptance remain deferred.
Browser interaction checks use preview fixtures, not real SSH services.
This is a prerelease for validation; v0.8.0 remains the stable release.
