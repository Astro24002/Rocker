# Rocker v0.7.0-rc.4

This prerelease improves Host cards and the Port Forwarding overview. Host
cards now put the platform mark beside the Host name and SSH user, with
favorite and edit actions revealed on hover or keyboard focus. Sidebar brand,
feature, and session marks have been realigned at compact sizes.

The forwarding overview groups saved rules by Host, with the two most recently
created rules visible per Host and the rest expandable. Each rule shows its
status on one line and offers separate details, start/pause, delete, and SSH
command copy actions. Pausing stops the local listener and releases its
connection lease while keeping the saved rule restartable; deletion requires
confirmation and clears the deleted rule from this window's PF sessions. SSH
commands reflect the saved bind, remote target, and Host SSH port; unavailable
or unsafe inputs cannot be copied as commands.

When a remote service refuses a forwarding channel, Rocker closes only that
client socket. The local forwarding listener and SSH lease remain in place so
the next local connection can work when the remote service returns.

The browser preview uses demonstration data, not live SSH/SFTP. Native
Windows/macOS installation, real-host forwarding, and SFTP transfer smoke
remain necessary before the final v0.7.0 release. The SFTP page still has no
visible transfer queue or restart-safe transfer resume.
