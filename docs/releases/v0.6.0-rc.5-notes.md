Rocker v0.6.0-rc.5 is a prerelease of the unified desktop SSH workspace.

Session rows now expose a small trailing close control on pointer hover or
keyboard focus. It dispatches the existing guarded Close command, including the
established confirmation and lifecycle behavior, without activating the row or
switching workspaces. In the compact Sidebar the close control replaces the
Session kind icon while hovered so the controls do not overlap.

The bottom Target, Type, and Status strip has been removed. SSH, SFTP, and PF
content now uses the full Content Stage while each Session retains its existing
independent runtime and content state.

This candidate does not change Electron IPC contracts, persistent storage, SSH
or PTY ownership, or port-forwarding leases. SFTP remains a workspace route with
persisted browser-state metadata rather than a real directory transfer service,
and PF Browser Preview remains unavailable until HTTP/HTTPS is explicit.
