# Rocker v0.7.2

This patch release fixes SFTP directory copy and drag-and-drop behavior.

- Local and remote directories can be copied recursively in either direction
  as one transfer task. The original files remain in place.
- Dragging from the remote pane to a local directory now starts a download to
  that directory. Folder selection is also available in the local upload
  picker.
- The source row remains unavailable while its transfer is active, and the
  destination pane refreshes when the transfer finishes.
- Refreshing a remote listing after deleting an item no longer clears the
  current pane's Show hidden files selection. Opening a different SFTP session
  still starts with hidden files off.

Transfers are runtime-only and are not resumed after application restart. No
storage migration is required.
