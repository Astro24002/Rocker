# Rocker v0.7.0-rc.3 Verification

Date: 2026-09-20
Source: `dev/v0.7-sftp`; release tag `v0.7.0-rc.3`

## Scope

- Sidebar feature and session icons/labels are enlarged and aligned; the
  brand mark is not a navigation action. Compact session rows do not expose
  a close button, but retain the Close context-menu command.
- SSH session Port forwarding opens the same host-specific PF page and
  single-host PF session as the Hosts entry, without creating a forward.
- Hosts cards fit up to seven columns at wide content widths and reflow at
  narrower widths. Port Forwarding text is larger and rule tables can scroll.
- Windows work-area maximization respects a visible taskbar and changes in
  available work area; normal window bounds survive maximization/restoration.
- No storage schema migration or connection/forwarding/transfer lifecycle change.

## Candidate Limitations

Windows visible/auto-hidden taskbar behavior has unit coverage but has not
been manually verified on Windows. Browser-only previews are demo data, not
proof of real SSH/SFTP connectivity. The SFTP page has no visible transfer
queue/progress and transfers do not resume across restarts. Windows/macOS
packaged installation and real-host smoke remain manual final-release gates.
